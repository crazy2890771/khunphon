# ขุนพลพเนจร

เกมสามก๊กเทิร์นเบสแนว TS Online เล่นบนเว็บ มือถือ และ iPad ได้ทั้งออนไลน์และออฟไลน์

## วิธีเล่น
- เปิดลิงก์ GitHub Pages ของ repo นี้ใน Safari หรือ Chrome
- iPhone/iPad: กดปุ่มแชร์ → "เพิ่มไปยังหน้าจอโฮม" จะได้ไอคอนแอป เล่นได้แม้ไม่มีเน็ต

## เซฟเกม
- เซฟเก็บในเครื่องที่เล่นเท่านั้น
- ย้ายเครื่อง: ปุ่ม ⚙ มุมขวาบน → บันทึกเป็นไฟล์ / คัดลอกรหัส แล้วนำเข้าที่เครื่องใหม่
- ควรบันทึกเป็นไฟล์สำรองไว้เป็นระยะ

## ไฟล์
- `index.html` ตัวเกมทั้งหมด
- `sw.js` ทำให้เล่นออฟไลน์ได้ (เปลี่ยนเลขเวอร์ชันทุกครั้งที่อัปเดตเกม)
- `manifest.webmanifest` + `icon-*.png` ข้อมูลแอปและไอคอน
- `sprites/` ภาพตัวละคร ฉาก และไอคอน
